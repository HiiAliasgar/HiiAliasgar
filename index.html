I’m a Computer Science Engineer
building intelligent software.

I’m Aliasgar Lohawala, a Computer Science and Engineering undergraduate specialising in Artificial Intelligence and Machine Learning at Chhatrapati Shivaji Maharaj University. My interests sit at the intersection of software engineering and applied AI: designing useful applications, connecting intelligent models to real workflows, and making systems dependable beyond a successful demo.

I work primarily with Python and have been developing across backend services, REST APIs, data processing, machine learning fundamentals and modern web technologies. I’m especially interested in large language model applications, retrieval-augmented generation, tool-using agents and multi-agent systems. I enjoy understanding how each layer fits together—from the data and API design to model integration, user experience and deployment.

My project work includes AccidentGuard, an experimental Android application exploring motion-sensor signals for crash-candidate detection; an AI engineering agent that inspects GitHub repositories and requires human approval before proposing changes; a multi-agent research workflow for web and academic-source synthesis; and a document question-answering application built around retrieval-augmented generation.

Alongside project development, I’m strengthening my Python, data structures and algorithms, software design, testing and applied machine learning skills. I value clear problem-solving, readable code, careful validation and honest communication about limitations. I’m working towards contributing to engineering teams where I can build practical software, learn from experienced developers and steadily grow as an AI engineer.
