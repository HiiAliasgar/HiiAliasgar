## About

I am a Computer Science student focused on AI engineering. I build and study practical software involving Python, machine learning fundamentals, LLM APIs, retrieval-augmented generation, backend services, and Android prototypes.

My approach is to understand the problem, build a working implementation, test its behaviour, document limitations, and improve it. I distinguish experimental prototypes from verified functionality rather than presenting unfinished work as production-ready.

## Current Focus

- Strengthening Python, data structures and algorithms.
- Building LLM applications, RAG workflows, and tool-using agents.
- Improving backend engineering with FastAPI, databases, and automated tests.
- Evaluating models and documenting project results clearly.
