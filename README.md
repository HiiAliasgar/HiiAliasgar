## Engineer by training. Builder by obsession.

I am a Computer Science student focused on AI engineering and practical software development. I work with Python, LLM APIs, retrieval-augmented generation, backend services and applied machine learning.

I approach projects as engineering work: define the problem, understand the constraints, implement the system, test its behaviour, document limitations and iterate. I aim to make my repositories useful to another engineer—not just visually impressive.

## Flagship work

### [AccidentGuard — Smartphone-Based Experimental Accident Detection](https://github.com/HiiAliasgar/Accident-Guard)

An Android-focused prototype exploring whether smartphone motion sensors can help identify crash-like events and support a location-aware alert workflow.

- **Mobile stack:** React, TypeScript, Vite and Capacitor.
- **Android integration:** native Android build and device sensor access.
- **Detection focus:** accelerometer and gyroscope signals, thresholds and false-positive considerations.
- **Location workflow:** foreground location permission and map display.
- **Engineering focus:** testability, Android build reliability and CI validation.

**Status:** experimental student project. It is not a certified safety product and must not be relied on for emergency response.
